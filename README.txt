SSB ACADEMY - CODEMAGIC-READY ANDROID PROJECT

WHAT THIS ZIP IS
- An Android Studio project prepared for a cloud APK build on Codemagic.
- Includes codemagic.yaml and a Gradle launcher script.
- Includes an offline in-app course interface, lessons, practice questions, timer and streak tracker.
- It is a project source ZIP, not an APK yet.

BUILD IT WITH CODEMAGIC
1. Download and extract this ZIP.
2. Create a GitHub repository.
3. Upload the CONTENTS of this extracted folder to the repository root.
   Important: codemagic.yaml, gradlew, settings.gradle and build.gradle must be at the repository root.
4. Open https://codemagic.io/ and sign in.
5. Add the GitHub repository as an app.
6. Choose the codemagic.yaml workflow named "SSB Academy Android APK".
7. Start the build.
8. When it succeeds, open Artifacts and download app-debug.apk.
9. Open the APK on your Android phone to install it. Android may ask you to allow installation from your browser/files app.

FREE PLAN NOTE
Codemagic's official docs currently describe 500 free build minutes/month for individual personal accounts on macOS M2. Linux/Windows build minutes may be billed, so check the current plan and selected machine before starting. Do not enable billing or enter payment details if you cannot pay. The workflow here selects mac_mini_m2 because Codemagic documents free monthly minutes for personal accounts on M2 machines. Confirm the current allowance shown in your account before building; if it displays a charge or asks to enable billing, stop and do not continue.

CONTENT LIMITATION
No real teacher-recorded MP4 lectures are included. Lessons are original text/slide-style content. Add only videos you own or are authorised to use.

APP LIMITATION
This is an early learning prototype, not a complete SSB coaching platform. Review all lesson material and quiz content before relying on it for exam preparation.
